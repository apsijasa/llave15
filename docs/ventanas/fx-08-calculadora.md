# FX-08 — Calculadora de costos

Publicar en Replit propaga la tabla `cost_profiles` vacía. El cambio es aditivo: no hay datos que migrar ni script que correr. Cada taller guarda su perfil desde `/taller/calculadora`, con un usuario que tenga `costs.view`.

La calculadora solo sugiere precios; no cambia precios del inventario ni del catálogo.
